# rekordboxへの取り込み

1. 音源の入ったドライブを接続する。このM3U8は音源を含まず、作成したPCの絶対パスを参照する。ファイルを移動した場合は再照合する。
2. `unmatched.csv`で未一致や複数候補を確認する。未一致の曲はM3U8に含まれない。詳しい元の位置番号と判断理由は`report.json`にある。
3. rekordboxで［ファイル］→［インポート］→［プレイリストをインポート］を選び、`playlist.m3u8`を開く。バージョンにより表記が異なる場合がある。
4. 追加されたプレイリストの名前を必要に応じて変更する。曲順はトラック番号順で確認する。曲名・BPMなど別の列で並べ替えていると元の順番と異なって見える。
5. 件数、先頭・末尾の曲、同じ曲が複数回登場する箇所、リミックス版を確認する。重複する参照はM3U8に保持しているが、rekordboxが重複を整理した場合はアプリ側での対応が必要。スクリプトの検証だけでGUIの動作を保証しない。
6. 既存コレクションと同じファイルパスを使う。音源を別の場所へ複製したり、既存コレクションを削除して再取り込みしたりしない。キューやビートグリッドを再設定する必要があるとは限らない。自動解析の設定も確認する。

この処理は既存rekordboxライブラリ、音源、キューを直接編集していない。新規プレイリストとして取り込み、既存プレイリストを置き換える場合は別途判断する。

公式手順: [rekordbox 7.2.14 日本語マニュアル](https://cdn.rekordbox.com/files/20260409170202/rekordbox7.2.14_manual_JA.pdf)
