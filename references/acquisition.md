# 許可された音源の取得

このSkillのPython補助スクリプトは音声をダウンロードしない。音声取得はCodexが公式ページを操作する段階に分離する。ブラウザ操作が利用できない場合は公式ページと必要操作を示し、ユーザーが保存したファイルから続行する。

## SoundCloud

1. 未一致レポートの元曲リンクを公式SoundCloudページで開く。Spotify由来なら、アーティストの公式アカウント・曲名・バージョン・長さを確認してから対応を確定する。別ユーザーの無断転載と疑われるものは選ばない。
2. 必要ならユーザー自身のログインを待つ。パスワード・セッションcookieを読み出さない。
3. 曲のメニュー等にある公式の「Download file / ファイルをダウンロード」を使う。SoundCloudはプレイリスト全体を公式に一括ダウンロードする機能を提供していないため、対象曲ごとに確認する。Go/Go+のオフライン保存はrekordboxに渡すローカル音源とは扱わない。
4. 完了したファイルだけを記録する。HTML、ショートカット、ゼロバイト、不完全ダウンロード、DRM付きファイルを対応付けない。ダウンロード先の音源は安定したユーザー指定フォルダに置く。勝手に既存ファイルを上書きしない。
5. 元の曲の位置番号・ソースURL・取得日時・取得方法（公式Download file）・保存先・許可根拠を`overrides.json`に記録する。トークン付きCDN URLや非公開共有トークンは記録しない。音源タグと長さを確認し、必要ならユーザーの確認を得てからbuildする。

## その他の権利者配布・購入済み音源

公式アーティストサイト、レーベル、正規販売店に限定し、明示的なダウンロード許諾またはユーザーの購入権限を確認する。単なる「free download」という曲名や第三者ページの主張は根拠にしない。任意ドメインへのURLをスクリプトに渡して一括取得する仕組みは追加しない。

購入、メール登録、フォロー、投稿、外部アプリへのアカウント権限付与などを必要とする場合、既存の依頼に含まれるか確認する。許可された音源が見つからない場合は`unmatched.csv`に残して完了する。全曲が揃うまで権限を越えて探し続けない。
